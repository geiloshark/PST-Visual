# PST-Visual

Repository for the **pstom** R package and a standalone Shiny interface for running it locally.

## Contents

- `pstom/` — R package source (om, pdyn, dynplot)
- `shiny-app/` — standalone Shiny app (three tabs: om → pdyn → dynplot)

## Running the Shiny app

Open an R console and run:

```r
shiny::runApp("shiny-app")
```

See `shiny-app/README.md` for full install instructions and field reference.
